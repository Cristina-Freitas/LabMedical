# LabMedical
Projeto Avaliativo Senai-Lab365 - Módulo 1, Front-end.
## Sobre o projeto
Software audacioso para gestão de inventário médico

## Funcionalidades
- exibir,
- cadastrar,
- editar,
- pesquisar e
- excluir informações de pacientes, consultas e exames;

A aplicação tem as seguintes rotas:
- /login
- /inicio
- /pacientes
- /consultas
- /exames
- /lista
- /prontuario

## Tecnologias utilizadas:
- Angular v17
- TypeScript, HTML e CSS
- ngPrime
- Git com GitHub;
- Trello para organização e divisão das atividades

## Instalação
1. Certifique-se de ter o @angular/cli na sua máquina
2. Clone o repositório para sua máquina local.
3. Navegue até o diretório raiz do projeto.
4. Instale as dependências utilizando o comando:
     #### `npm install`.
5. Inicie o aplicativo Angular utilizando o comando: `npm start`no terminal, ou ng serve
